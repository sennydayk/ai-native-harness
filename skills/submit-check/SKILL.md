# submit-check — 제출 전 점검

## 체크리스트
1. PLAN.md 맨 위 제출 체크리스트(README 원문 기준) 항목마다 **실제 파일 경로**를 찾아 표시한다. 파일명·위치·형식이 정확한지.
2. 새 터미널에서 README의 실행 방법을 **그대로 따라 실행**해 동작을 확인한다 (e2e-check L1).
3. README에 포함: 무엇을 만들었나 / 실행 방법 / 구조 요약 / 구현·부분 구현·미구현 목록 / 문서 안내(PLAN, DOMAIN, DECISIONS, RISKS, USER_GUIDE).
4. 계획·협업 기록 문서가 요구되면: 판단과 근거, 검증 결과, 남은 한계가 들어 있는지.
5. 불필요한 대용량 파일, 비밀값, 임시 파일이 없는지.
6. 모든 파일 저장 상태 확인 → `git status`가 깨끗한지 → 최종 커밋 `chore: 제출 정리`.
7. `git log --oneline`으로 작업 흐름이 읽히는지 확인한다.
8. 확인 결과를 사람에게 표로 보고한다 (항목 / 상태 / 증거).
