# oral-prep — 이해도 점검 질문 만들기

## 입력
- 코드, PLAN, DOMAIN, DECISIONS, RISKS, E2E_RESULT, git log

## 질문 10개 (유형별로 섞어서)
- 설계 근거: "X 구조를 고른 이유와 이 요구에서 적절한 이유"
- 범위 판단: "Y를 구현하지 않은 이유"
- 실무자 반영: "어떤 답변이 설계를 바꿨나"
- 동작 설명: 특정 함수·로직이 어떻게 동작하고 어디서 실패할 수 있나 (파일:함수 명시)
- 장애·리스크: "Z 입력이 들어오면? 장애가 나면 어떻게 대응하나"
- 검증: "결과가 맞다는 걸 어떻게 확인했나"
- AI 통제: "AI 제안 중 받아들이지 않은 것과 이유"
- **전제가 틀린 질문 1개**: 실제 구현과 다른 전제를 깐 질문 (사람이 바로잡는 연습용)
- 확장: "규모가 10배가 되면 무엇이 먼저 문제가 되나"

## 규칙
- **답을 쓰지 않는다.** 질문과, 근거가 되는 파일 위치만 제시한다.
- 질문은 이 결과물에만 해당하는 구체적인 것으로 (일반론 금지).
- 사람이 답할 때 쓰는 틀: 결론 → 근거(실무자 답변·데이터) → 대안과 버린 이유 / 약점 → 파급 → 다음 검증·개선 계획.
