# handoff — 인수인계

## 모드 1: 세션 인수인계
**언제**: 큰 단계 전환(발굴→구현, 구현→검증) / 응답이 느려지거나 엉뚱해짐 / 같은 실수 반복 / 컨텍스트 요약이 반복될 때
1. `HANDOFF.md`(templates 복사)를 채운다: 목표 / 현재 단계 / 핵심 결정 3개(DECISIONS 참조) / 동작하는 것 / 안 되는 것 / 다음 할 일 1~3개 / 실행 방법 / 주의.
2. 커밋한다.
3. 새 세션 첫 요청: "AGENTS.md와 HANDOFF.md를 읽고, 필요한 경우에만 PLAN.md·DOMAIN.md의 관련 섹션을 읽은 뒤 '다음 할 일' 1번부터 진행해."
- HANDOFF는 짧게 (한 화면). 대화 내용을 복붙하지 않는다.

## 모드 2: 현업 인수인계
**언제**: 제출 20~30분 전
1. `USER_GUIDE.md`(templates 복사)를 **실무자의 언어로** 쓴다: 해결되는 것 / 사용 순서 / 화면이 보여주는 것과 판단 규칙(실무자가 말한 기준 그대로) / 데이터 바꾸는 법 / 아직 안 되는 것 / 다음 제안.
2. 기술 용어를 줄인다. 실행 방법 같은 기술 내용은 README에 둔다.
3. 구현되지 않은 것을 된다고 쓰지 않는다 (right-size-audit 결과와 일치).
