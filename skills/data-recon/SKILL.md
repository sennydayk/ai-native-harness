# data-recon — 제공 파일 탐색 (읽기 전용)

## 절차
1. 파일 목록: `find . -type f -not -path './.git/*' -not -path './node_modules/*' -not -path './harness/*'`
2. 데이터 파일마다 (전체를 읽지 않는다):
   - 크기·행 수 (`wc -l`), 앞부분 (`head -5`)
   - 컬럼·타입 추정, 결측 비율, 고유값 수가 적은 컬럼의 값 목록
   - 형식 불일치 (날짜·시간 형식 혼재, 단위, 대소문자, 공백), 중복 행, 범위를 벗어난 값
3. 기존 코드가 있으면: 진입점, 실행 방법, 의존성, 테스트 여부.
4. `EXPLORE.md`에 정리: 파일별 역할 / 스키마 / **품질 이슈 목록** / 실무자에게 확인할 점.

## 규칙
- 아무 파일도 수정하지 않는다.
- 품질 이슈의 처리 방법(제외·보정·표시)은 정하지 않고 질문으로 남긴다 → ask-draft(선택형)로 실무자에게 묻는다.
- 분석에는 짧은 스크립트(pandas 등)를 쓰고 출력은 요약만 보여준다.
